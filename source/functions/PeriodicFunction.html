PeriodicFunction

Provides a periodic function by repeating a user-supplied base function in time and/or any of the three Cartesian coordinate directions

Description

The PeriodicFunction takes a user-supplied base function, and periodically repeats that function in time or any of the three Cartesian coordinate directions. The function can be repeated in any combination of these directions or time.

The resulting function repeats the base function's behavior over the interval from 0 to the specified period in a given dimension. This is repeated indefinitely, and is also repeated (rather than mirrored) for negative values of the coordinates or time.

Example Input Syntax

[Functions<<<{"href": "../../syntax/Functions/index.html"}>>>]
  [periodic_xyzt]
    type = PeriodicFunction<<<{"description": "Provides a periodic function by repeating a user-supplied base function in time and/or any of the three Cartesian coordinate directions", "href": "PeriodicFunction.html"}>>>
    base_function<<<{"description": "The function used as a basis for the generated periodic function."}>>> = base_xyzt
    period_x<<<{"description": "The period for repetition of the base function in the x direction"}>>> = 1
    period_y<<<{"description": "The period for repetition of the base function in the y direction"}>>> = 1
    period_z<<<{"description": "The period for repetition of the base function in the y direction"}>>> = 1
    period_time<<<{"description": "The period for repetition of the base function in time"}>>> = 1
  []
[]
