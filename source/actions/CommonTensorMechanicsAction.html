Common Tensor Mechanics Action

Description

This CommonTensorMechanicsAction action adds the parameters supplied at the [/Physics/SolidMechanics/QuasiStatic] level as defaults for all the subblocks within the QuasiStatic block. See the description, example use, and parameters on the SolidMechanics/QuasiStatic action system page.

commentnote

It performs the same action on the deprecated [Modules/TensorMechanics/Master] and [Modules/TensorMechanics/DynamicMaster] syntaxes.
