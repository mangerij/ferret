WaveEquationCoefficient

Material for use as coefficient (where a is a scalar coefficient) in standard-form Helmholtz wave equation applications with derivatives calculated using automatic differentiation.

Overview

This object provides a ready-to-use coefficient for the electric field Helmholtz wave equation problem, specifically a coefficient material property of the form

where

  • is the complex wave number ( where is the wavelength),

  • is the complex relative electric permittivity, and

  • is the complex relative magnetic permeability.

Note that all of these parameters (real and imaginary parts) can be provided by the user as material properties.

Example Input File Syntax

[Materials<<<{"href": "../../syntax/Materials/index.html"}>>>]
  [wave_equation_coefficient]
    type = WaveEquationCoefficient<<<{"description": "Material for use as coefficient $a k^2 \\mu_r \\epsilon_r$ (where a is a scalar coefficient) in standard-form Helmholtz wave equation applications with derivatives calculated using automatic differentiation.", "href": "WaveEquationCoefficient.html"}>>>
    k_real<<<{"description": "Wave number, real component."}>>> = k_real_mat
    k_imag<<<{"description": "Wave number, imaginary component."}>>> = k_imag_mat
    eps_rel_real<<<{"description": "Relative permittivity, real component."}>>> = 1
    eps_rel_imag<<<{"description": "Relative permittivity, imaginary component."}>>> = 0
    mu_rel_real<<<{"description": "Relative permeability, real component."}>>> = 1
    mu_rel_imag<<<{"description": "Relative permeability, imaginary component."}>>> = 0
  []

# problem: -(cu')' - k^2 * u = -F , 0 < x < L, u: R -> C
# u(x=0) = g0 , u(x=L) = gL
# k = a + jb
#     a = a(x) =  2 * (1 + x/L)
#     b = b(x) =      (1 + x/L)
# c = d + jh
#     d = d(x) = 12 * (1 + x/L)^2
#     h = h(x) =  4 * (1 + x/L)^2
# L = 10

[Mesh]
  [gmg]
    type = GeneratedMeshGenerator
    dim = 1
    xmin = 0
    xmax = 10
    nx = 100

[]

    family = LAGRANGE

  [u_imag]

    family = LAGRANGE

[]
