ComputeRotatedCubicParentElectrostrictiveStrain

Computes the electrostrictive eigenstrain eps_ij = Q_ijkl P_k P_l of a cubic parent phase whose crystal axes are turned by the material property twist about z.

Overview

Computes the electrostrictive eigenstrain of a cubic parent phase (with , as in ComputeCubicParentElectrostrictiveStrain) whose crystal axes are turned about by the material property twist (radians). At twist it reduces to the unrotated object.

commentnote:Rotated crystal axes

The crystal axes are turned about by the material property twist (radians); the polarization, its gradient and the strain are expressed in the crystal frame, the cubic expressions are evaluated there and the result is turned back. For the displacement equation to see the same crystal, ComputeElasticityTensor must be given euler_angle_3 twist (in degrees).

Example Input File Syntax

[./electrostrictive_eigenstrain]
  type = ComputeRotatedCubicParentElectrostrictiveStrain
  polar_x = polar_x
  polar_y = polar_y
  polar_z = polar_z
  eigenstrain_name = 'ferro'
  block = '0'
