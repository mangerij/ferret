PerpendicularElectricFieldInterface

VectorInterfaceKernel that implements the condition

Overview

PerpendicularElectricFieldInterface is a vector InterfaceKernel object that implements the condition

where

  • is the electric permittivity on the primary side of the interface,

  • is the electric permittivity on the secondary side of the interface,

  • is the perpendicular component of the electric field vector on the primary side of the interface,

  • is the perpendicular component of the electric field vector on the secondary side of the interface, and

  • is the free electric charge on the interface.

Example Input File Syntax

[InterfaceKernels<<<{"href": "../../syntax/InterfaceKernels/index.html"}>>>]
  [perpendicular]
    type = PerpendicularElectricFieldInterface<<<{"description": "VectorInterfaceKernel that implements the condition $\\epsilon_1 \\vec{E}_{1}^{\\perp} - \\epsilon_2 \\vec{E}_{2}^{\\perp} = \\sigma_f$", "href": "PerpendicularElectricFieldInterface.html"}>>>
    variable<<<{"description": "The name of the variable that this residual object operates on"}>>> = u
    neighbor_var<<<{"description": "The variable on the other side of the interface."}>>> = v
    boundary<<<{"description": "The list of boundaries (ids or names) from the mesh where this object applies"}>>> = primary0_interface
    primary_epsilon<<<{"description": "Permittivity on the primary side of the interface (default = 1.0)."}>>> = 1.0
    secondary_epsilon<<<{"description": "Permittivity on the secondary side of the interface (default = 1.0)."}>>> = 10.0
    free_charge<<<{"description": "Free charge on the interface (default = 0)."}>>> = 1.0
  []

# epsilon_1 = 10.0

    input = subdomain1
  []
  [interface]

    paired_block = '1'
    new_boundary = 'primary0_interface'
  []
[]
