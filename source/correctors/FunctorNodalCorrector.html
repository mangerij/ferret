FunctorNodalCorrector

Set (all or some) values of (one or more) nonlinear variable(s) using functor evaluations

Design

The FunctorNodalCorrector is derived from the NodalUserObject, so it can change primary variable values for degrees of freedom located on nodes (boundary-restricted if desired).

commentnote

Except for constant monomials, Lagrange variable, and other simple FE families, simply setting variable DOFs using targeted evaluations may not give the expected result of a variable following closely the functor values over the domain of interest.

Input Parameters

  • functorsFunctors to compute the new variable values with. A functor is any of the following: a variable, a functor material property, a function, a postprocessor or a number.

    C++ Type:std::vector<MooseFunctorName>

    Unit:(no unit assumed)

    Controllable:No

    Description:Functors to compute the new variable values with. A functor is any of the following: a variable, a functor material property, a function, a postprocessor or a number.

  • variables_to_correctVariables to change the value of.

    C++ Type:std::vector<VariableName>

    Unit:(no unit assumed)

    Controllable:No

    Description:Variables to change the value of.

Required Parameters

  • blockThe list of blocks (ids or names) that this object will be applied

    C++ Type:std::vector<SubdomainName>

    Controllable:No

    Description:The list of blocks (ids or names) that this object will be applied

  • boundaryThe list of boundaries (ids or names) from the mesh where this object applies

    C++ Type:std::vector<BoundaryName>

    Controllable:No

    Description:The list of boundaries (ids or names) from the mesh where this object applies

  • excluded_nodesetsVector of nodesets to skip execution on

    C++ Type:std::vector<BoundaryName>

    Controllable:No

    Description:Vector of nodesets to skip execution on

  • functor_evaluation_techniquenode_argHow to evaluate the functor

    Default:node_arg

    C++ Type:MooseEnum

    Options:node_arg

    Controllable:No

    Description:How to evaluate the functor

    Controllable:No

    Description:In the case where this UserObject is depended upon by an initial condition, allow it to be executed twice during the initial setup (once before the IC and again after mesh adaptivity (if applicable).

    Options:XFEM_MARK, NONE, INITIAL, LINEAR, LINEAR_CONVERGENCE, NONLINEAR, NONLINEAR_CONVERGENCE, POSTCHECK, TIMESTEP_END, TIMESTEP_BEGIN, MULTIAPP_FIXED_POINT_END, MULTIAPP_FIXED_POINT_BEGIN, MULTIAPP_FIXED_POINT_CONVERGENCE, MULTISYSTEM_FIXED_POINT_ITERATION_END, FINAL, CUSTOM, TRANSFER

    Controllable:No

    Description:The list of flag(s) indicating when this object should be executed. For a description of each flag, see https://mooseframework.inl.gov/source/interfaces/SetupInterface.html.
