RotatedWallEnergyDerivative

Calculates the residual for the gradient (domain wall) energy of a cubic parent phase, with the crystal axes turned by the material property twist about z. Takes the bare gradient coefficients G11, G12, G44.

Overview

Calculates the residual contribution of the gradient (domain wall) energy

with the cubic tensor , , , for a crystal whose axes are turned about by the material property twist (radians). Unlike WallEnergyDerivative, which takes G110 and the ratios G11_G110, ..., this object takes the bare coefficients G11, G12, G44 and has no antisymmetric (G44P) term; at twist the two agree for G110 = G11, G11_G110 = 1, G12_G110 = G12/G11, G44_G110 = G44/G11, G44P_G110 = 0. The energy is computed by RotatedWallEnergy.

Example Input File Syntax

[./walled_x]
  type = RotatedWallEnergyDerivative
  variable = polar_x
  component = 0
  block = '0'
[../]
