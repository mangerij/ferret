BlockOrientationFromUserObject

The BlockOrientationFromUserObject vector postprocessor collects Euler angle (degrees) information for each material block from a user object, such as ComputeBlockOrientationByRotation or ComputeBlockOrientationByMisorientation, and structures the data into four columns:i.e., subdomain_id, euler_angle_0, euler_angle_1 and euler_angle_2.

Example Input File Syntax

[VectorPostprocessors<<<{"href": "../../syntax/VectorPostprocessors/index.html"}>>>]
  [block_ea]
    type = BlockOrientationFromUserObject<<<{"description": "Output the Euler angle for each block computed from average of quaternions.", "href": "BlockOrientationFromUserObject.html"}>>>
    block_orientation_uo<<<{"description": "Name of ComputeBlockOrientation user object for updated block orientation."}>>> = block_orientation
  []
[]
(../moose/modules/solid_mechanics/test/tests/block_orientation/block_orientation_calculation.i)
