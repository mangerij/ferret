CrystalPlasticitySlipResistanceGSS

Description

CrystalPlasticitySlipResistanceGSS derives from CrystalPlasticitySlipResistance which calculates slip resistance in crystal plasticity system. The slip resistance can be a function of state variables .

Input Parameters

  • variable_sizeThe userobject's variable size.

    C++ Type:unsigned int

    Controllable:No

    Description:The userobject's variable size.

Required Parameters

  • blockThe list of blocks (ids or names) that this object will be applied

    Controllable:No

    Description:The list of blocks (ids or names) that this object will be applied

  • uo_state_var_nameName of state variable property: Same as state variable user object specified in input file.

    C++ Type:std::string

    Controllable:No

    Description:Name of state variable property: Same as state variable user object specified in input file.
