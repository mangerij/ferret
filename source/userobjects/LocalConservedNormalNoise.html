LocalConservedNormalNoise

Gaussian normal distributed random number noise provider for the ConservedLangevinNoise kernel.

Overview

Provides a normally distributed random number (Box-Muller) at every quadrature point, regenerated at the start of each time step, for noise kernels such as LocalConservedLangevinNoise and the thermal-field route of MasterInteractionCartLLGHConst.

  • conserved = true (default) subtracts the volume average, so the noise integrates to zero, as needed for conserved (concentration-type) fields. Use conserved = false for non-conserved order parameters and for macrospins, where the uniform mode is physical.

  • white_noise = true divides each value by . The noise is then space-time white with unit strength, so a source has the fluctuation-dissipation covariance with the consistent mass matrix . The stochastic Landau-Lifshitz-Bloch equation uses this (Finite-temperature micromagnetics).

MOOSE reseeds random objects at every step with seed + timestep. Give independent noise objects seeds that differ by more than the number of time steps; otherwise their streams repeat each other, shifted in time.

Example Input File Syntax

[UserObjects<<<{"href": "../../syntax/UserObjects/index.html"}>>>]
  [hx_noise]
    type = LocalConservedNormalNoise<<<{"description": "Gaussian normal distributed random number noise provider for the ConservedLangevinNoise kernel.", "href": "LocalConservedNormalNoise.html"}>>>
    conserved<<<{"description": "Subtract the volume average so the noise integrates to zero (concentration-type fields); false keeps the uniform mode (non-conserved order parameters, macrospins)"}>>> = false
    white_noise<<<{"description": "Divide each value by sqrt(JxW dt): space-time white noise with unit strength, so a source -test*sqrt(2D)*value has the fluctuation-dissipation covariance 2D M/dt (M the consistent mass matrix)"}>>> = true
    seed<<<{"description": "The seed for the master random number generator"}>>> = 1
