The parameter "include_scaling_factor" controls whether the residual/Jacobian scaling factor (associated with the selected solution variable) should be included in the norm. For the purposes of convergence monitoring, it is usually recommended to keep this as false, as residual/Jacobian scaling factors are usually intended to improve numerical conditioning of the system rather than convergence criteria, although in some instances a user may deliberately be selecting scaling factors to influence residual-based convergence using the Executioner/resid_vs_jac_scaling_param; in this case the user likely wishes to set include_scaling_factor = true.
