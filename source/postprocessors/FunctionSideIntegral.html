FunctionSideIntegral

Computes the integral of a function over a boundary.

The sideset may be an internal or external boundary. The function is evaluated at each quadrature point on the specified sideset. The default quadrature rule is used for integration.

Example input syntax

In this example test, we compute a few function integrals on the boundaries of the domain. Since the mesh is Cartesian, the integrals are known.

[Postprocessors<<<{"href": "../../syntax/Postprocessors/index.html"}>>>]
  [./zmin]
    # no function is provided, so it should default to 1
    # yielding postprocessor = 8
    type = FunctionSideIntegral<<<{"description": "Computes the integral of a function over a boundary.", "href": "FunctionSideIntegral.html"}>>>
    boundary<<<{"description": "The list of boundary IDs from the mesh where this object applies"}>>> = back
  [../]
  [./zmax]
    # result should be -6*area_of_zmax_sideset = -48
    type = FunctionSideIntegral<<<{"description": "Computes the integral of a function over a boundary.", "href": "FunctionSideIntegral.html"}>>>
    boundary<<<{"description": "The list of boundary IDs from the mesh where this object applies"}>>> = front
    function<<<{"description": "This postprocessor will return the integral of this function over the boundary"}>>> = '-z'
  [../]
  [./ymin]
    # since the integrand is odd in x, the result should be zero
    type = FunctionSideIntegral<<<{"description": "Computes the integral of a function over a boundary.", "href": "FunctionSideIntegral.html"}>>>
    boundary<<<{"description": "The list of boundary IDs from the mesh where this object applies"}>>> = bottom
    function<<<{"description": "This postprocessor will return the integral of this function over the boundary"}>>> = 'x*pow(z,4)'
  [../]
  [./ymax]
    # result should be 24
    type = FunctionSideIntegral<<<{"description": "Computes the integral of a function over a boundary.", "href": "FunctionSideIntegral.html"}>>>
    boundary<<<{"description": "The list of boundary IDs from the mesh where this object applies"}>>> = top
    function<<<{"description": "This postprocessor will return the integral of this function over the boundary"}>>> = 'y*(1+x)*(z-2)'
  [../]
  [./xmin_and_xmax]
    # here the integral is over two sidesets
    # result should be 432
    type = FunctionSideIntegral<<<{"description": "Computes the integral of a function over a boundary.", "href": "FunctionSideIntegral.html"}>>>
    boundary<<<{"description": "The list of boundary IDs from the mesh where this object applies"}>>> = 'left right'
    function<<<{"description": "This postprocessor will return the integral of this function over the boundary"}>>> = '(3+x)*z'
  [../]
[]
