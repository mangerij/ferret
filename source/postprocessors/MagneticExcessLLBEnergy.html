MagneticExcessLLBEnergy

Overview

Useful tracker of the Landau-Lifshitz-Bloch implementation where,

is computed in the simulation box (volume ). This Postprocessor tracks the deviations of the normalized magnetization vector from unity. The energy here is arbitrary (and unitless) but can be cast into real units by using the prefactor energyscale included in the object input parameters.
