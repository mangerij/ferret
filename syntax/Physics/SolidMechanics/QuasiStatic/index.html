Solid Mechanics QuasiStatic Physics System

Set up stress divergence kernels with coordinate system aware logic

The QuasiStatic Physics is the recommended way to set up a static or quasi-static solid mechanics problem. From a compact set of parameters it creates the displacement variables, the strain calculator, the stress-divergence kernels, and the requested outputs – consistently and with the correct settings – so you do not have to assemble these objects by hand.

The parameters are organized into the groups below; each group points to the reference documentation for the underlying theory. The complete parameter list appears at the bottom of this page.

Variables

Declare the displacement field the problem solves for (and any coupled temperature). Set "add_variables" to have the action create the displacement variables at the order matching the mesh.

  • "displacements"

  • "add_variables"

  • "temperature"

  • "scaling"

Strain

Choose the kinematic model, apply eigenstrains, correct volumetric locking, and tune the strain time integration. strain = FINITE selects large-deformation kinematics and SMALL selects small-deformation kinematics; eigenstrains are subtracted from the total strain; volumetric_locking_correction applies the stabilization for linear elements; and the kinematic approximation and generalized-midpoint weight control how the incremental deformation is integrated. See Kinematics, Kinematic Approximations, Stabilization, and Generalized Midpoint Rule.

  • "strain"

  • "volumetric_locking_correction"

  • "volumetric_locking_correction_mode"

  • "kinematic_approximation"

  • "generalized_midpoint_alpha"

  • "eigenstrain_names"

  • "automatic_eigenstrain_names"

  • "strain_base_name"

Lagrangian Formulation

Select the total or updated Lagrangian formulation. The two produce identical results, so choose whichever is more convenient (homogenization requires TOTAL). See Balance of Linear Momentum.

  • "new_system"

  • "formulation"

Homogenization

Impose cell-average stress or strain constraints on a periodic unit cell (total Lagrangian only). See Homogenization.

  • "constraint_types"

  • "targets"

  • "homogenized_off_diagonal_jacobian"

Output

Add AuxVariables that output stress and strain tensor components and derived scalar quantities. See Visualizing Tensor Components for the available quantities.

  • "generate_output"

  • "material_output_order"

  • "material_output_family"

Plane Stress and Plane Strain

Impose out-of-plane conditions for two-dimensional models.

  • "planar_formulation"

  • "scalar_out_of_plane_strain"

  • "out_of_plane_pressure"

Advanced

Subdomain restriction, automatic differentiation, and residual/Jacobian output.

  • "block"

  • "base_name"

  • "use_automatic_differentiation"

  • "global_strain"

  • "save_in"

  • "diag_save_in"

Example Input File Syntax

A small deformation, total Lagrangian problem:

[Physics<<<{"href": "../../index.html"}>>>]
  [SolidMechanics<<<{"href": "../index.html"}>>>]
    [QuasiStatic<<<{"href": "index.html"}>>>]
      [all]
        strain<<<{"description": "Strain formulation"}>>> = SMALL
        add_variables<<<{"description": "Add the displacement variables"}>>> = true
        new_system<<<{"description": "If true use the new LagrangianStressDiverence kernels."}>>> = true
        formulation<<<{"description": "Select between the total Lagrangian (TOTAL) and updated Lagrangian (UPDATED) formulations for the new kernel system."}>>> = TOTAL
        volumetric_locking_correction<<<{"description": "Flag to correct volumetric locking"}>>> = true
        generate_output<<<{"description": "Add scalar quantity output for stress and/or strain"}>>> = 'cauchy_stress_xx cauchy_stress_yy cauchy_stress_zz cauchy_stress_xy cauchy_stress_xz cauchy_stress_yz strain_xx strain_yy strain_zz strain_xy strain_xz strain_yz'

[Physics<<<{"href": "../../index.html"}>>>]
  [SolidMechanics<<<{"href": "../index.html"}>>>]
    [QuasiStatic<<<{"href": "index.html"}>>>]
      [./all]
        strain<<<{"description": "Strain formulation"}>>> = FINITE
        add_variables<<<{"description": "Add the displacement variables"}>>> = true
      [../]
    [../]
  []
[]
(../moose/modules/solid_mechanics/test/tests/finite_strain_elastic/finite_strain_elastic_new_test.i)
[Physics<<<{"href": "../../index.html"}>>>]
  [SolidMechanics<<<{"href": "../index.html"}>>>]
    [QuasiStatic<<<{"href": "index.html"}>>>]
      # parameters that apply to all subblocks are specified at this level. They
      # can be overwritten in the subblocks.
      add_variables<<<{"description": "Add the displacement variables"}>>> = true
      strain<<<{"description": "Strain formulation"}>>> = FINITE
      generate_output<<<{"description": "Add scalar quantity output for stress and/or strain"}>>> = 'stress_xx'

      [./block1]
        # the `block` parameter is only valid insde a subblock.
        block<<<{"description": "The list of ids of the blocks (subdomain) that the stress divergence kernels will be applied to"}>>> = 1
      [../]
      [./block2]
        block<<<{"description": "The list of ids of the blocks (subdomain) that the stress divergence kernels will be applied to"}>>> = 2
        # the `additional_generate_output` parameter is also only valid inside a
        # subblock. Values specified here are appended to the `generate_output`
        # parameter values.
        additional_generate_output<<<{"description": "Add scalar quantity output for stress and/or strain (will be appended to the list in `generate_output`)"}>>> = 'strain_yy'
      [../]
    []
  []

Parameters supplied at the [Physics/SolidMechanics/QuasiStatic] level act as defaults for its sub-blocks.

commentnote

With automatic_eigenstrain_names = true, eigenstrain names are populated only under restrictive conditions for classes such as CompositeEigenstrain, ComputeReducedOrderEigenstrain, and RankTwoTensorMaterialADConverter. Set automatic_eigenstrain_names = false and list the names manually if these components need to be included.
